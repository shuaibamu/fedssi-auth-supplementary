# Data

The datasets are not redistributed. Download them and place the files as follows; compare the SHA-256 digests with `data_checksums.txt`.

* `data/rt/RT_IOT2022.csv` — RT-IoT2022, UCI Machine Learning Repository, https://doi.org/10.24432/C5P338
* `data/cic/*.csv` — CIC-IDS2017 "MachineLearningCSV" files (eight daily files), Canadian Institute for Cybersecurity
